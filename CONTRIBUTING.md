# Contributing

This SDK is generated from Typeship's API specification. Generated source changes arrive through a Typeship pull request with an API compatibility report, package-version check, and this repository's build and test gate.

Do not hand-edit generated source. Open an issue here with the operation, expected behavior, and a minimal reproduction; maintainers will fix the specification or generator and regenerate the package.

Changes to repository infrastructure, examples, and documentation that are not generated are welcome as normal pull requests.
